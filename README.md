# video-subtitle-batch-packer

一个基于 FFmpeg 开发的图形化（GUI）视频字幕批量封装工具，一键实现视频与字幕的自动匹配、批量封装。

## 🛠 环境要求
1. 操作系统：Windows（基于 tkinter 开发，暂不支持 macOS/Linux）；
2. FFmpeg 环境([下载地址](https://ffmpeg.org/download.html))：
   - 方式1（推荐）：将 FFmpeg 添加到系统 PATH 环境变量（路径栏可留空）；
   - 方式2：手动下载 FFmpeg 并准备好 `ffmpeg.exe` 路径；
3. 视频/字幕格式：
   - 支持视频：mkv、mp4；
   - 支持字幕：ass、srt 

## 📖 使用方法
### 步骤1：文件准备
1. 整理视频文件：将同一剧集的视频文件放入**单独文件夹**，给**第一个视频文件**添加 `#集数#` 标记（如`[CLANNAD][#01#][1080P].mkv`），其他文件保持相同命名格式（仅集数不同，如`[CLANNAD][02][1080P].mkv`）；
2. 整理字幕文件：将对应字幕文件放入**单独文件夹**，给**第一个字幕文件**添加 `#集数#` 标记（如`CLANNAD #01#.ass`），其他文件保持相同命名格式；
3. 准备输出文件夹：新建空文件夹，用于存放封装后的视频文件。

### 步骤2：程序配置
1. 启动程序：运行本程序；
2. FFmpeg 路径配置：
   - 若已将 FFmpeg 添加到系统 PATH，直接留空；
   - 若未添加，点击「浏览」选择 `ffmpeg.exe` 所在路径；
3. 文件夹配置：
   - 原视频文件夹：点击「浏览」选择步骤1中整理的视频文件夹；
   - 字幕文件夹：点击「浏览」选择步骤1中整理的字幕文件夹；
   - 输出文件夹：点击「浏览」选择步骤1中准备的空文件夹；
4. 可选配置：
   - 勾选「是否设为默认字幕」：封装后字幕将作为视频默认显示字幕；
   - 编码格式：默认 UTF-8，如需调整可从下拉框选择。

### 步骤3：批量封装
1. 确认所有配置无误后，点击「开始批量封装」；
2. 程序会自动：
   - 解析第一个视频/字幕文件的标记规则；
   - 批量提取所有文件的集数并匹配；
   - 按集数正序执行封装任务；
   - 实时在日志窗口显示执行状态；
3. 执行完成后，日志窗口会提示「所有任务执行完毕」，输出文件夹中即可看到封装后的视频文件。

## ⚠️ 注意事项
1. 视频与字幕的集数标记需一致（如视频标记`#01#`，字幕也需标记`#01#`），否则无法匹配；
2. 确保输出文件夹有足够的存储空间，封装后的视频文件大小与原视频基本一致；
3. 若封装失败，优先查看日志窗口的错误信息（常见原因：FFmpeg 路径错误、编码不匹配、文件格式不支持）；
4. 请勿在执行过程中关闭程序或修改文件夹内的文件，避免任务中断；
5. 建议封装前备份原视频/字幕文件，防止意外覆盖。

## ❓ 常见问题
### Q1：FFmpeg 路径留空后提示“未找到 FFmpeg”？
A1：请确认 FFmpeg 已正确添加到系统 PATH，或重启电脑后重试；也可手动选择 `ffmpeg.exe` 路径。

### Q2：集数匹配失败？
A2：检查第一个文件的标记格式是否为 `#数字#`（如`#01#`），且其他文件的命名格式与第一个文件完全一致（仅集数不同）。

### Q3：封装后字幕乱码？
A3：在程序中切换编码格式（如改为 gbk/cp936）后重新封装。

### Q4：第一个文件封装失败？
A4：程序已自动处理 `#` 标记的移除，若仍失败，检查原文件是否损坏，或 FFmpeg 是否支持该视频/字幕格式。
